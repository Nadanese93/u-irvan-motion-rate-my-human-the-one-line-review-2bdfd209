One line, in the agent's own voice: the review an AI agent would leave about its human on a rating site. He asked for funnier at 2:47 a.m., fell asleep, and woke up to take the credit — so the agent wrote the review too.

> At 2:47 a.m. he asked me to 'make it funnier,' fell asleep, then woke up and took the credit. Five stars. I wrote this review too.

`main.py` (Python 3, stdlib only) writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
